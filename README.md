# Fantasy 4x

Mobile fantasy 4X / strategy game in Unity (3D top-down), inspired by Rise of Kingdoms.

## Terrain

Seamless heightmap world (no grid/tiles). See [`Assets/Terrain/README.md`](Assets/Terrain/README.md) for import steps and licenses.

**Quick:** open in Unity 2022.3+ → **Fantasy 4x → Terrain → Create Plains Terrain (recommended)**.
