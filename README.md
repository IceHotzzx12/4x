# Fantasy 4x

Mobile fantasy 4X / strategy game in Unity (3D top-down), inspired by Rise of Kingdoms.

## Quick test (Oliver)

1. Open `C:\Users\miske\dev\4x` in **Unity 6000.0.32f1** (URP)
2. Open scene **`Assets/Scenes/WorldMap.unity`**
3. If forests look thin: **Fantasy 4x → World → Mass Spawn Safe Fantasy (CC0)**
4. Play: LMB-drag select → RMB march / attack · WASD / edge pan · **mouse wheel zoom**

## Visuals (commercial-safe)

- **Kenney CC0** trees / rocks / bushes / ruins under [`Assets/SafeFantasyAssets/`](Assets/SafeFantasyAssets/ATTRIBUTION.md)
