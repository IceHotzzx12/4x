# Fantasy 4x

Mobile fantasy 4X / strategy game in Unity (3D top-down), inspired by Rise of Kingdoms.

## Quick test (Oliver)

1. Open in **Unity 2022.3+**
2. **Fantasy 4x → Terrain → Create Plains Terrain (recommended)**
3. **Fantasy 4x → Gameplay → Spawn Test Scenario** (bakes NavMesh + spawns 3 blue / 3 red capsules)
4. Play: LMB-drag select → RMB march / attack barbarians · WASD / edge / wheel camera
