GameDevGary — 50 Free .PNG Heightmaps (CC0 subset for Fantasy 4x)

Continuous 16-bit grayscale heightmaps for Unity Terrain / TerrainData.
Not a tile, hex, or chunk mesh kit — one height field = one seamless landscape.

In this folder:
- 2K/     — all 10 maps at ~2017×2017 (16-bit grayscale), good for mobile prototyping
- 4K-key/ — Plains, Mountains, Hills, Meadows, Canyons, Wetlands at ~4033×4033

Full original pack (all resolutions including 8K) remains available at the itch.io source URL above
(445 MB zip; not mirrored here due to store size limits).

Recommended for RoK-style open world:
- Plains / Meadows → open-field marches
- Mountains / Hills / Canyons → natural movement barriers
- Wetlands → soft barriers / riverine lowlands (combine with river mask pack)

Target Unity repo: https://github.com/IceHotzzx12/4x
